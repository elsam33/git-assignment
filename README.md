# Sample Project

This repository contains a simple Python script that prints sample data stored in a list of dictionaries.

## Files
- `sample_data.py` – Python script with example records and prints them using a loop.
- `README.md` - This documentation file explaining how the project works and how to run it.

## Requirements
- Python 3.X installed

## How to Run
1. Clone the repository
2. Navigate into the folder
3. Run: `python sample_data.py`
